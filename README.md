# Java DSA Regular Practice

A personal, ongoing collection of Data Structures and Algorithms practice in
Java. The goal is to build consistency, understand problem-solving patterns,
and keep solutions from daily practice in one place.

## Study resources

- [Striver's A2Z DSA Course/Sheet](https://takeuforward.org/strivers-a2z-dsa-course/strivers-a2z-dsa-course-sheet-2/)
- [NeetCode Roadmap](https://neetcode.io/roadmap)

Use Striver's sheet as the main topic-by-topic study path and NeetCode as a
complementary roadmap for revisiting patterns and organizing interview
practice. This repository is a learning log; it does not claim that every
problem on either resource is completed.

## What you'll find here

The current practice files contain Java examples and solutions covering
topics such as:

- Array fundamentals, searching, and rotation
- Hash maps, counting, and frequency problems
- Two-pointer techniques
- String problems, including anagrams and rotations
- Basic recursion

The files are informal practice notes and may contain several standalone
solutions in one file. Some snippets are written for online-judge method
signatures, so they may need to be separated into appropriately named Java
files and given a driver before compiling as a complete program.

## Suggested practice routine

1. Pick the next topic or problem from Striver's sheet.
2. Try the problem independently before looking at hints or a solution.
3. Write the Java solution and check edge cases and complexity.
4. Compare the approach with NeetCode or other explanations when useful.
5. Add the solution and note the topic or pattern in the practice file.
6. Revisit difficult problems after a few days.

## Progress

Practice is ongoing. The numbered `Streak_*` files record work across
practice sessions; their numbering is a personal log, not a claim of full
course completion.
